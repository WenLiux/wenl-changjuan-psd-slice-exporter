# 完整长图导出

长卷项目现在支持两种互不混淆的导出内容：

- **切片导出**：按照 PSD / PSB 内的切片结构输出多个文件，可选择部分切片。
- **完整长图**：忽略切片选择，读取整张合成画布并输出 1 个 PNG 或 JPEG 文件。

## 客户端使用

在“导出设置”的“导出内容”中选择“完整长图”。随后仍可使用原始宽度或指定宽度：

- 原始宽度：保持 PSD / PSB 合成画布的原始尺寸；
- 指定宽度：按整张画布等比例缩放，高度自动计算；
- JPEG 的质量、背景色和色彩策略继续有效；
- 输出目录会使用“原文件名_full_original”或“原文件名_full_目标宽度px”命名；
- 文件名包含最终尺寸，例如“详情切片_full_1440x31044.png”。

完整长图模式不读取或拼接切片文件，而是直接编码已经校验过的内嵌合成图；因此不会再次触发 419px 等旧式切片缩放问题。默认仍保持原文件只读，并生成同样的验证报告。

## 内存保护

指定宽度时，完整长图需要一次性生成目标画布。程序会在导出前估算目标 RGBA 画布占用；超过安全上限时会停止并提示降低目标宽度，或改用切片导出。这个保护只针对完整长图，不会改变现有切片导出的低内存策略。

## 命令行

~~~powershell
python scripts/export_full_image.py input.psd
python scripts/export_full_image.py input.psb --width 2160 --format jpeg
~~~

命令行也支持现有的 JPEG 质量、背景色、色彩策略、ZIP 和 Photoshop 回退参数。完整导出的机器可读结果通过验证报告确认尺寸、格式、ICC 配置和（原尺寸无损 PNG 时）像素一致性。
