# Stage 1 - Slice Models and Parsers

## Status

Stage 1 is complete. The legacy exporter remains unchanged. New production
code now provides typed V6/V7/V8 parsing and explicit automatic-slice policy.

## Added modules

```text
app/models/slice_info.py
app/core/slice_parser.py
```

## Unified model

`SliceInfo` preserves:

- original record index;
- Photoshop slice ID;
- slice name;
- left, top, right, and bottom;
- automatic-slice flag;
- source resource version;
- origin metadata;
- slice type metadata.

It exposes calculated width, height, bounds, and full-canvas checks.

`SliceParseResult` separates:

- all parsed slices;
- sorted exportable slices;
- excluded slices;
- structured warnings and errors.

## Parser behavior

V6:

- reads `SlicesV6.items`;
- maps `[left, top, right, bottom]`;
- preserves name, origin, type, and ID.

V7/V8:

- reads descriptor records;
- supports byte and string descriptor keys;
- normalizes enumerated origin and type values;
- preserves name and ID.

All exportable slices are sorted by:

```text
top, left, original index
```

## Automatic-slice policy

- Explicit `autoGenerated` slices are excluded.
- Explicit user-generated full-canvas slices are retained.
- Full-canvas slices with missing or unknown origin are retained and reported
  as ambiguous.
- A document containing only automatic slices produces no exportable slices
  and a structured `only_automatic_slices` warning.
- Invalid and out-of-canvas slices are excluded with structured errors.
- Duplicate bounds are retained and reported for later user review.

This replaces the legacy heuristic that removed every full-canvas slice when
multiple records existed.

## Compatibility evidence

The new parser was compared with the Stage 0 baseline:

| Fixture | Resource | Parsed | Exportable | Automatic excluded |
| --- | ---: | ---: | ---: | ---: |
| Verified PSD | V8 | 15 | 14 | 1 |
| Verified PSB | V6 | 15 | 14 | 1 |

For both files, all 14 normalized exportable bounds exactly match the legacy
pixel-verified outputs.

The legacy CLI regression tests still pass and its file was not modified in
Stage 1.

## Remaining gap

A real Photoshop-produced V7 file is still unavailable. The V7 descriptor path
has synthetic coverage and uses the same psd-tools descriptor representation
as V8, but a real V7 fixture should be added when one becomes available.

## Stage 2 entry conditions

Stage 2 may now create a high-fidelity composite reader that:

- explicitly identifies embedded merged data;
- never silently invokes layer re-rendering;
- reports ICC, mode, depth, alpha, dimensions, and reliability;
- returns a typed result when no merged composite exists;
- leaves Photoshop fallback implementation for its dedicated later stage.
