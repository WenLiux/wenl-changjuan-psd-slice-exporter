## 这个版本解决了什么

- 新增“不切片完整导出长图”模式：整张画布输出为一个 PNG 或 JPEG 文件。
- 完整长图支持原始宽度、指定宽度、禁止放大、JPEG 质量和背景设置。
- 完整长图输出继续使用安全的临时文件和验证流程，不修改原始 PSD / PSB。
- 从“指定宽度”切回“原始宽度”时，目标宽度立即显示文档真实宽度。
- 修复 PSD / PSB 文件拖拽读取链路，并保留选择文件入口。

## Web UI 交互优化

- 导出设置卡片使用独立内部滚动容器，滚动条不会越过卡片圆角边界。
- 鼠标跟随光效在内部滚动后仍能同步当前位置。
- 优化完整长图 / 切片导出的模式切换、按钮文案和状态提示。
- 保留克制的卡片悬浮反馈、选项切换动效和控件状态反馈。
