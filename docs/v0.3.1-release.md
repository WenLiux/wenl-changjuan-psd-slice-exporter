# WENL / 长卷 v0.3.1 发布说明

## 发布内容

- WENL / 长卷品牌化 WebView2 客户端。
- 顶部当前文档信息区与精简关于页。
- 修复 PSD / PSB 原生文件拖拽读取。
- 原始宽度与指定宽度切换时显示正确的目标宽度。
- 深色界面固定使用浅色品牌标识。
- 新增 WENL 长卷 Windows 多尺寸程序图标。
- 设置目录迁移至 `%APPDATA%\WENL\Changjuan`，旧设置无损复制。
- 验证报告使用 WENL / 长卷品牌名称。

## 发布文件

- 程序：`WENL-Changjuan.exe`
- 便携版目录：`WENL-Changjuan-Windows-x64-v0.3.1`
- 压缩包：`WENL-Changjuan-Windows-x64-v0.3.1.zip`

程序为 onedir 便携版，必须保留 `WENL-Changjuan.exe` 与 `_internal`
文件夹的相对位置。
