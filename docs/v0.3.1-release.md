## 这个版本解决了什么

Photoshop 旧式切片导出可能受到 8192 像素长边限制，导致超长 PSD / PSB 在导出时被整体缩小。例如原本 1440px 宽的画布，切片可能只剩约 419px。

WENL 长卷直接读取文档切片信息和内嵌合成图，按照原始坐标导出，默认保留文件原宽度；也可以统一指定新的目标宽度，并保持所有切片的比例与对齐关系。

## v0.3.1 版本亮点

### 全新的 WENL 长卷客户端

- 使用 WebView2、React 与 TypeScript 构建品牌化桌面界面。
- 重新组织文档信息、切片列表、预览和导出设置。
- 增加克制的卡片悬浮反馈、选项切换动效和控件状态反馈。
- 深色界面固定使用浅色品牌标识，避免黑色 Logo 与背景混在一起。
- 新增 Windows 多尺寸程序图标与 WENL 长卷品牌信息。

### 更准确的宽度逻辑

- 支持按 PSD / PSB 原始宽度导出。
- 支持输入指定目标宽度，并统一换算全部切片。
- 从“指定宽度”切回“原始宽度”时，目标宽度会立即恢复为文档真实宽度，避免误解。
- 可禁止放大，只允许缩小或保持原尺寸。

### 文件读取与导出体验

- 修复 PSD / PSB 文件拖拽后无法读取的问题。
- 支持选择文件或直接拖入窗口。
- 支持切片单选、全选与全不选。
- 支持 PNG、JPEG、透明背景、JPEG 质量和颜色策略。
- 支持进度、取消、打开输出目录和查看验证报告。
- 同一文档可以重复调整参数并导出，无需再次解析。

### 设置迁移

- 新设置目录：`%APPDATA%\WENL\Changjuan\settings.json`
- 首次启动时会无损复制旧版设置。
- 旧设置文件不会被删除。
- Photoshop 启动、模式转换等高风险许可只对本次运行有效，不会永久保存。

## 首次使用

1. 下载并完整解压 Windows ZIP。
2. 双击 `WENL-Changjuan.exe`。
3. 将 PSD / PSB 拖入窗口，或点击“选择文件”。
4. 选择“原始宽度”或填写指定宽度。
5. 选择需要导出的切片、格式和输出目录。
6. 点击“开始导出”。
7. 完成后打开输出目录，或查看验证报告。

## 高保真与安全机制

- 文件只在本机处理，不会上传到网络。
- 原始 PSD / PSB 只读，不会被覆盖或保存。
- 默认使用文档内嵌合成图，不会主动联系 Photoshop。
- 只有明确选择后才会使用 Photoshop 高保真回退。
- Photoshop 回退处理的是经过验证的系统临时副本。
- 程序只关闭自己创建的临时文档，不会退出 Photoshop。
- 回退前后会核对原文件的 SHA-256、大小与修改时间。

> [!WARNING]
> 使用 Photoshop 回退前，请先保存并关闭 Photoshop 中已经打开的文档。v0.3.1 的 Photoshop 回退仅支持 8 位 RGB 文档。
