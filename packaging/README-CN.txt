WENL 长卷｜PSD / PSB 高保真切片导出工具 0.3.2
================================================

启动
----

双击 WENL-Changjuan.exe。

0.3.2 使用 WebView2 渲染网页式桌面界面，并支持切片导出和完整长图导出。
Windows 10 / 11 通常已
包含 WebView2 Runtime；若启动时提示缺失，请安装 Microsoft Edge
WebView2 Runtime 后重试。

请保持整个文件夹完整，不要只把 EXE 单独移走；_internal 文件夹是程序
运行所需的组件。

基本使用
--------

1. 将 PSD / PSB 拖入顶部区域，或点击“选择文件”。
2. 等待文档信息和切片列表加载完成。
3. 在“导出内容”中选择“切片导出”或“完整长图”。
4. 选择“原始宽度”，或输入自定义目标宽度，例如 1440、750。
5. 切片模式下选择需要导出的切片，再选择 PNG/JPEG、色彩策略和输出目录。
6. 点击对应的导出按钮。
7. 完成后可直接打开输出目录或验证报告。

程序不会覆盖旧结果。每次导出都会创建新的安全目录。

Photoshop 高保真回退
--------------------

默认不调用 Photoshop。只有选择“合成图不可用时”或“总是使用
Photoshop”才会使用回退。

使用前请保存并关闭 Photoshop 中所有打开的文档。程序只会打开源文件
的临时副本，不会保存或修改原 PSD / PSB，也不会退出 Photoshop。

如果 Photoshop 没有运行，需勾选“本次允许启动 Photoshop”。此授权
不会保存。

设置
----

普通设置保存在：

%APPDATA%\WENL\Changjuan\settings.json

如果检测到旧版设置，程序会自动复制到新目录，并保留旧文件。

允许启动 Photoshop、色彩/模式转换、使用未验证合成图等安全授权不会
保存，每次都需要明确选择。
